# Session Log

Use this file to preserve important progress across sessions.

## Format

```text
YYYY-MM-DD · lane/session-type · summary · reference
```

## Entries

```text
YYYY-MM-DD · product/plan · created product plan for <feature> · lanes/product/plans/<file>.md
YYYY-MM-DD · coding/handover · prepared execution handover for <ticket> · handovers/<file>.md
YYYY-MM-DD · release/checklist · prepared release checklist for <version> · lanes/release/specs/<file>.md
```
